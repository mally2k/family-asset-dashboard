## 📁 데이터 구조

엑셀 파일(`유주네 자산 현황.xlsx`)은 다음 시트로 구성됩니다:

| 시트 | 내용 |
|------|------|
| `총 자산 현황` | 월별 총자산, 순자산, 부채 요약 |
| `상세 자산` | 예금/적금/주식/개인연금/가상화폐 상세 내역 |
| `대출` | 부채(대출) 상세 내역 |
| `목적별 현황` | 주택/노후/자녀/여행 등 목적별 집계 |

## 📝 데이터 업데이트 방법

### 방법 1: 관리자 업데이트 버튼 (추천)
1. 구글 시트에서 `유주네 자산 현황` 시트 수정
2. 대시보드 헤더의 **🔄 버튼** 클릭 → 관리자 비밀번호 입력
3. 약 1~2분 후 자동으로 최신 데이터 반영 (모든 기기에 적용)

> 동작 원리: 대시보드 → Cloudflare Worker(비밀번호 검증) → GitHub Actions가 구글 시트를 다운로드해 `data.json` 갱신 → Pages 자동 배포
> 설정 방법은 `worker/README.md` 참고

### 방법 2: GitHub에 엑셀 푸시
1. 수정된 `유주네 자산 현황.xlsx`을 GitHub 저장소에 push
2. GitHub Actions가 자동으로 `data.json` 갱신
